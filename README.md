# Programação Linear — Atividades Interativas

Este repositório reúne materiais didáticos, atividades interativas e recursos digitais para o ensino de Programação Linear no Ensino Médio.

## Projeto disponível

### Escape Room da Programação Linear

Jogo web educativo em HTML, CSS e JavaScript. A proposta coloca os estudantes em uma missão interativa na qual precisam resolver desafios sobre variáveis de decisão, restrições, função objetivo, região viável e comparação de vértices para encontrar uma solução ótima.

Pasta do projeto:

escape-room-programacao-linear/

Arquivo principal do jogo:

escape-room-programacao-linear/index.html

## Conteúdos trabalhados

- Variáveis de decisão.
- Restrições lineares.
- Região viável.
- Função objetivo.
- Comparação de vértices.
- Tomada de decisão matemática.
