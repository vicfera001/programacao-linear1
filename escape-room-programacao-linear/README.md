# Escape Room da Programação Linear

Jogo web educativo para estudantes do ensino médio. A missão é escapar de um laboratório resolvendo enigmas sobre programação linear, coletando itens e usando a chave final para abrir a porta.

## Como jogar

1. Abra `index.html` em um navegador.
2. Clique nos objetos da sala.
3. Resolva os desafios para coletar itens matemáticos.
4. Use a Chave Final para abrir a porta de saída.

## Conteúdos trabalhados

- Variáveis de decisão.
- Restrições e região viável.
- Função objetivo.
- Comparação de vértices para encontrar uma solução ótima.
